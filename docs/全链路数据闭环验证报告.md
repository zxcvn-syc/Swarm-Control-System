## 1. 全链路架构

```text
┌─────────────┐    /target_track     ┌───────────────┐    /task_assignment    ┌───────────────┐    /drone_states    ┌─────────────────┐    /enclosure_command
│ tracker_node│ ───────────────────▶ │ scheduler_node│ ─────────────────────▶ │ planner_node  │ ─────────────────▶ │ enclosure_node│ ───────────────────▶ 封控执行
│  （感知）    │   TargetTrackArray   │    （调度）     │     EnclosureCommand   │   （规划）      │   DroneStateArray  │    （封控）      │    EnclosureCommandArray
└─────────────┘                      └───────────────┘                        └───────────────┘                    └─────────────────┘
                                                                                          ▲
                                                                                          │
                                                                    /uav1/current_pose    │
                                                                                   PoseStamped
```

- **tracker_node（T1）**：感知目标，发布 `TargetTrackArray` 到 `/target_track`
- **scheduler_node（T2）**：接收目标信息，分配无人机任务，发布 `EnclosureCommand` 到 `/task_assignment`
- **planner_node（T3）**：接收任务分配，规划无人机航点/状态，发布 `DroneStateArray` 到 `/drone_states`
- **enclosure_node（T4）**：接收无人机状态 + 实时位姿，计算动态 Voronoi 封控点，发布 `EnclosureCommandArray`

## 4. 关键问题与修复记录

### 4.1 scheduler_pkg 模块导入错误

**现象**：

```text
ModuleNotFoundError: No module named 'logger_config'
```

**根因**：scheduler_pkg 内部使用绝对导入，ROS2 entry point 加载时找不到同级模块。

**修复**（commit `58ab739`）：

- `scheduler_pkg/auction_engine.py`：`from logger_config import logger` → `from .logger_config import logger`
- `scheduler_pkg/scheduler.py`：`from agent import Agent` 等 → `from .agent import Agent` 等
- `main_greedy.py` / `main_auction.py`：try/except 兼容相对导入和直接脚本执行

**验证**：T2 正常启动并持续输出 summary，无崩溃。

### 4.2 DroneState 字段兼容

**现象**：旧版 `swarm_interfaces` 生成的 `DroneState` 缺少 `platform_type` 字段。

**修复**（commit `7d4ca1f`）：在 `enclosure_node.on_pose` 中使用 `hasattr(state, "platform_type")` 保护。

### 4.3 PoseStamped 订阅与双数据源合并

**实现**（commit `6c57093`）：

- `enclosure_node` 新增订阅 `/uav1/current_pose`（`geometry_msgs/PoseStamped`）
- 双数据源：`_batch_drones`（来自 `/drone_states`）+ `_pose_drones`（来自 PoseStamped）
- `_merged_drones()` 合并，实时位姿优先覆盖
- `dirty` 标记触发 Voronoi 重算

**验证**（L3）：改变无人机位置后，封控点方向同步变化。
