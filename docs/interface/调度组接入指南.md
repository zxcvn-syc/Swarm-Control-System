## 3. 与感知组对接字段映射

`perception_pkg` 发布 `TargetTrackArray`，其中每条 `TargetTrack` 字段：

| TargetTrack 字段 | 调度组如何用 |
|------------------|--------------|
| `target_id`      | 直接写入 `TaskAssignment.target_id`（**必须保持 ID 透传**） |
| `x`, `y`         | 距离代价的输入；二维调度够用 |
| `vx`, `vy`       | 暂未使用（预留给 C2 预测代价） |
| `confidence`     | 映射为 priority ∈ [0,1]（已确认还会 +0.1 提升） |
| `is_confirmed`   | 已确认的目标优先级 +0.1 |
| `cls` / `motion_mode` / `pred_*` | C2 接管 |

`DroneStateArray.drones[]` 字段映射：

| DroneState 字段 | 调度组如何用 |
|------------------|--------------|
| `drone_id`       | 写入 `TaskAssignment.drone_id` |
| `x`, `y`         | 距离代价的输入 |
| `z`, `vx`, `vy`, `vz` | 当前未使用 |
| `available=false` | 从可用池中剔除 |

## 4. 分配算法选择建议

| 场景 | 推荐策略 | 理由 |
|------|----------|------|
| 目标数 ≫ 无人机数 | **`greedy`** | O(N·M·K)，最简单稳定 |
| 目标数 ≈ 无人机数 | **`hungarian`** | 全局最优 1-to-1 |
| 单机多目标（>1） | **`greedy`** | 匈牙利需要把无人机列复制 K 次，代价函数容易失控 |
| 演示 / 比赛 | **`greedy`** | 默认值 = greedy，不会因为 scipy 缺失而炸 |

切换方式：

```bash
-p assignment_strategy:=hungarian
```

或 `config/scheduler.yaml` 里改 `assignment_strategy:`。

### 4.1 贪心策略（greedy）

每个无人机按距离递增顺序挑最近的**未分配**目标，最多 `max_per_drone` 个。
带 priority 权重：priority 越高 → cost 越低 → 越容易分配。

### 4.2 匈牙利策略（hungarian）

`scipy.optimize.linear_sum_assignment` 解一个 N×M 代价矩阵。当
`max_per_drone > 1` 时，把无人机矩阵在行方向复制 K 次后再做匹配，然后
按 `row % N` 还原 drone index。

## 5. 配置参数

`config/scheduler.yaml`：

```yaml
scheduler_node:
  ros__parameters:
    num_drones: 8
    assignment_strategy: greedy       # greedy | hungarian
    max_per_drone: 2
    tick_period: 0.5
    log_interval_sec: 5.0
    target_topic: /target_track
    drone_topic: /drone_states
    output_topic: /task_assignment
    default_task_type: track
```

`task_type` 字段目前固定为 `track`，C2 会改成 `intercept` / `enclose` /
`patrol` 等。

## 8. 故障排查

| 现象 | 可能原因 | 解决 |
|------|----------|------|
| 启动报 `ModuleNotFoundError: swarm_interfaces` | 没重新编译 | `colcon build --packages-select swarm_interfaces` 并 `source install/setup.bash` |
| `assignment_strategy:=hungarian` 启动报 scipy 错 | 环境缺 scipy | `pip install scipy` 或改回 greedy |
| `/task_assignment` 没有消息 | 感知组还没发 `/target_track` | `ros2 topic echo /target_track` 看上游 |
| 调度一直 "no targets received" | 同上 | 等待感知组或检查 topic 名 |
