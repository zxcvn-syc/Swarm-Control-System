## 2. Phase 1 核心实现细节

### 2.1 tracker_node 接管 vendored cvtrack

- **文件**: `ros2_ws/src/perception_pkg/perception_pkg/tracker_node.py`
- 导入路径: `from cvtrack.runner import CvtrackRunner`（**不是** `/home/hhh/Downloads/cv_tracking_demo` 的引用 checkout）
- vendored cvtrack 位于 `perception_pkg/cvtrack/src/cvtrack/`
- Phase 1 前 tracker_node 可能指向过引用 checkout；Phase 1 后已确认锁定 vendored 版本

### 2.2 `_build_runner_overrides` 透传 kalman + trajectory_prediction

**文件**: `tracker_node.py` L170–263

以下 ROS2 参数被读取并注入 `CvtrackRunner.from_overrides`:

| ROS2 参数 | YAML 键 | 用途 |
|-----------|---------|------|
| `tracker.kalman.dt` | `dt` | KF 时间步 |
| `tracker.kalman.sigma_p` | `sigma_p` | 过程噪声 |
| `tracker.kalman.sigma_v` | `sigma_v` | 速度噪声 |
| `tracker.kalman.sigma_m` | `sigma_m` | 测量噪声 |
| `tracker.kalman.acceleration_gain` | `acceleration_gain` | 加速度增益 |
| `tracker.kalman.motion_threshold_slow` | `motion_threshold_slow` | 慢速阈值 |
| `tracker.kalman.motion_threshold_fast` | `motion_threshold_fast` | 快速阈值 |
| `trajectory_prediction.enabled` | `enabled` | 轨迹预测开关 |
| `trajectory_prediction.prediction_steps` | `prediction_steps` | 预测步数 |

### 2.3 motion_mode 字段透传

**文件**: `tracker_node.py` L500–504

```python
msg.motion_mode = int(getattr(rec, 'motion_mode', 0))
```

motion_mode 枚举:
- `0` = unknown
- `1` = stationary
- `2` = slow
- `3` = fast

## 4. D1 调试话题实现

### 4.1 /target_track_debug

**消息类型**: `swarm_interfaces/TargetTrackDebug`

**字段**:
- `header`: std_msgs/Header
- `tracks`: TargetTrack[] — 与主话题同步的完整 tracks
- `kf_covariance`: float64[] — 每个 track 9 元素（行优先 3×3 KF 协方差）
- `motion_mode_reasons`: string[] — motion_mode 对应的人类可读原因
- `appearance_scores`: float64[] — Re-ID 外观匹配分（-1.0 表示未使能）
- `source_topic`: string — 触发本次发布的输入 topic 名

**文件**: `tracker_node.py` L100–170（`_MetricsRecorder` 类）L620–648（`_publish_debug_track` 方法）

### 4.2 /tracking_metrics

**消息类型**: `diagnostic_msgs/DiagnosticArray`

**指标键值**:

| Key | 含义 |
|-----|------|
| `perception/id_switch_count` | 帧间 track ID 切换次数（累计） |
| `perception/miss_rate` | 丢失率 = miss / total_updates |
| `perception/convergence_time_ms` | KF 收敛时间（毫秒，均值） |
| `perception/active_tracks` | 当前活跃 track 数 |
| `perception/motion_mode_distribution` | 各 motion_mode 计数分布 |

**实现**: `_MetricsRecorder` 类（`tracker_node.py` L106–167），由 `_metrics_timer` 驱动（默认 1s 周期）

### 4.3 命令行参数

| 参数 | 类型 | 默认值 | 用途 |
|------|------|--------|------|
| `enable_debug_topics` | bool | True | 是否启用调试话题 |
| `metrics_period_ms` | int | 1000 | /tracking_metrics 发布周期（毫秒） |

## 5. 接口矩阵（跨包对接）

```
tracker_node (/target_track) → coord_transform_node → /target_track_world
                       ↓
              scheduler_pkg (scheduler_node)
              containment_pkg (enclosure_node)
```

| 生产者 | 话题 | 消费者 | 用途 |
|--------|------|--------|------|
| tracker_node | `/target_track` | coord_transform_node, scheduler_node | 像素坐标跟踪 |
| coord_transform_node | `/target_track_world` | scheduler_node, enclosure_node | 世界坐标 |
| tracker_node | `/target_track_debug` | 调试工具 | KF 协方差/外观分 |
| tracker_node | `/tracking_metrics` | 监控系统 | 性能指标 |
| tracker_node | `/enclosure_targets` | enclosure_node | 封控专用目标 |

## 6. 遗留项与阻塞原因

| 遗留项 | 优先级 | 阻塞原因 | 建议 |
|--------|--------|----------|------|
| 外观模型 (Re-ID) 使能 | 低 | 需要 YOLOv8-ReID 权重文件 | 提供 `appearance.weights` 参数路径后自动使能 |
| 多源轨迹融合 | 中 | 等待融合协议接口文档 | 建议与规划组对齐融合数据格式 |
| `kf_covariance` 真实值填充 | 低 | vendored cvtrack 当前未暴露 KF 协方差到 track record | 后续可修改 `Track` 类型增加 `kf_cov` 字段 |
