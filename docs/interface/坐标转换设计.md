# 坐标转换设计（C3 桥接节点）

## 背景

感知组发布的 `TargetTrack.x / y` 是图像像素坐标；调度组、封控组做无人机控制需要世界米制坐标。这中间缺一个桥接节点，把像素 → 相机系 → 无人机机体系 → 世界坐标系（ENU）。

## 输入 / 输出

| 方向 | Topic | 类型 | 备注 |
| --- | --- | --- | --- |
| 订阅 | `/target_track` | `swarm_interfaces/TargetTrackArray` | 感知组原始发布（像素） |
| 订阅 | `/camera_info` | `sensor_msgs/CameraInfo` | 一次性缓存 K 矩阵 |
| 订阅 | `/drone_pose` | `geometry_msgs/PoseStamped` | 无人机 ENU 位姿（来自飞控 / MAVROS） |
| 发布 | `/target_track_world` | `swarm_interfaces/TargetTrackArray` | 世界米制坐标（调度/封控用） |
| 发布 | `/target_track_debug` | `swarm_interfaces/TargetTrackArray` | 调试用（带 frame_id 标注） |

## 转换步骤（核心算法）

1. **像素 → 相机光学系**：用 `CameraInfo.K` 的逆矩阵，把 `(u, v)` 反投影到相机坐标系射线 `(Xc, Yc, 1)`。
2. **地面平面假设**：假设目标在 `Z_world = ground_altitude`（参数，默认 0 米）。把射线从相机位置投影到该平面，得到相机系下的 `(Xc, Yc, Zc)`。
3. **相机光学系 → 机身系**：应用固定的 `camera_optical → camera_link → base_link` 旋转（默认相机前向对齐机身，参数 `camera_mount_roll/pitch/yaw` 可覆盖）。
4. **机身系 → 世界系（ENU）**：用 `drone_pose` 的四元数 + 平移做刚体变换。
5. **KF 速度同步旋转**：把 `vx, vy`（像素/秒）先转到相机系再转到世界系。
6. **不确定性（协方差）**：如果提供，按同样的旋转矩阵 `R` 变换 `Σ_world = R · Σ_cam · Rᵀ`。

## 坐标系约定

- 相机光学系：`Xc` 右, `Yc` 下, `Zc` 前（OpenCV/ROS 惯例）。
- 机身系（base_link）：`Xb` 前, `Yb` 左, `Zb` 上（ROS REP-145 / PX4）。
- 世界系（ENU）：`X` 东, `Y` 北, `Z` 上。
- 地面假设：`Z_world = ground_altitude`（参数），默认 0。

## 关键参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `camera_info_topic` | `/camera_info` | CameraInfo 来源 |
| `drone_pose_topic` | `/drone_pose` | PoseStamped 来源 |
| `input_topic` | `/target_track` | 像素坐标订阅 |
| `output_topic` | `/target_track_world` | 世界坐标发布 |
| `ground_altitude` | 0.0 | 地面海拔（米，ENU Z） |
| `max_pose_age_s` | 0.5 | 姿态消息最大延迟（秒） |
| `camera_mount_roll` | 0.0 | 相机相对机身安装角 |
| `camera_mount_pitch` | 0.0 | 同上 |
| `camera_mount_yaw` | 0.0 | 同上 |

## 错误处理

- `/camera_info` 还没到 → 缓存，不发布。
- `/drone_pose` 还没到或超期 → 不发布（避免虚假坐标）。
- 像素在图像外 → 跳过该 track。
- 射线与地面平面近平行 → 跳过该 track（避免数值不稳定）。

## 已知限制

- 单相机、单无人机姿态（非多机融合）。
- 地面平面假设：忽略目标高度（树、车顶等）。
- 假定 `drone_pose` 已是 ENU；若为 NED 需后续做轴交换。
- 不做时间同步（用最近一条 drone_pose；可后续加 `message_filters`）。
